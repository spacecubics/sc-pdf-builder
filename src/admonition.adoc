== Admonitions

Admonitionは、本文から補足、ヒント、重要事項、警告などを目立たせ、
読み手の注意を促すためのブロックです。
Asciidoctorには、用途の異なる5種類のAdmonitionが用意されています。

=== Admonition Types

[cols="1,2,4",options="header"]
|===
|Type |Label |Purpose

|Note
|`NOTE`
|本文を理解するための補足情報を示します。

|Tip
|`TIP`
|便利な使い方、推奨事項、作業を簡単にするヒントを示します。

|Important
|`IMPORTANT`
|読み飛ばしてはいけない重要事項を示します。

|Warning
|`WARNING`
|将来発生する可能性がある問題や、期待しない結果への警告を示します。

|Caution
|`CAUTION`
|データ損失や機器への影響など、操作前に確認すべき危険を示します。
|===


Admonitionは、情報の重要度と読み手に求める対応に合わせて選択します。
通常の補足に `WARNING` や `CAUTION` を多用すると、本当に重要な警告が
目立たなくなるため、必要な箇所だけで使用してください。

=== Single-line Syntax

内容が一行の場合は、ラベルの後ろにコロンと半角スペースを付けて記載できます。

[source,asciidoc]
....
NOTE: これは補足情報です。

TIP: この方法を使用すると作業を簡略化できます。
....

実際の表示は次のとおりです。

NOTE: これは補足情報です。

TIP: この方法を使用すると作業を簡略化できます。

=== Block Syntax

複数行の文章や複数の段落を含める場合は、`====` で囲むブロック形式を使用します。

[source,asciidoc]
....
[WARNING]
====
この機能はコンバーターの内部実装に依存しています。

Asciidoctor PDFを更新した場合は、PDFを再生成して表示を確認してください。
====
....

実際の表示は次のとおりです。

[WARNING]
====
この機能はコンバーターの内部実装に依存しています。

Asciidoctor PDFを更新した場合は、PDFを再生成して表示を確認してください。
====

=== Display Examples

5種類のAdmonitionは、現在のテーマでは次のように表示されます。

[NOTE]
====
これは本文を補足する情報です。
====

[TIP]
====
これは作業を効率化するためのヒントです。
====

[IMPORTANT]
====
これは必ず確認する必要がある重要事項です。
====

[WARNING]
====
これは問題が発生する可能性を示す警告です。
====

[CAUTION]
====
これは操作前に確認する必要がある注意事項です。
====

=== Block Content

ブロック形式のAdmonitionには、段落だけでなく、リストやコードブロックなども記載できます。

[source,asciidoc]
....
[IMPORTANT]
====
PDFを公開する前に、次の項目を確認してください。

* 文書番号
* リビジョン
* 秘密区分
====
....

実際の表示は次のとおりです。

[IMPORTANT]
====
PDFを公開する前に、次の項目を確認してください。

* 文書番号
* リビジョン
* 秘密区分
====

=== Icons

`src/index.adoc` の `:icons: font` は、文字ラベルの代わりに
Asciidoctor PDFに組み込まれたFont Awesomeアイコンを表示します。

[source,asciidoc]
----
:icons: font
----

この属性を削除すると、アイコンの代わりに `NOTE`、`TIP`、`IMPORTANT`、
`WARNING`、`CAUTION` という文字ラベルが表示されます。

アイコンを使用する場合、種類ごとのアイコンと基本色はAsciidoctor PDFが提供します。
